# KUTKUT — Android MVP

KUTKUT is a TikTok-style short-video Android app starter built with Kotlin + Jetpack Compose + Media3.

## Included
- Vertical swipe video feed
- Auto-playing demo videos
- Like / save / comment / share UI
- Search screen
- Create/upload screen UI
- Inbox screen
- Profile screen
- Android Studio project structure

## Run
1. Install Android Studio.
2. Open this `KUTKUT` folder.
3. Let Gradle sync.
4. Connect an Android phone with USB debugging enabled, or start an emulator.
5. Press Run.

## Important
This is an MVP/front-end starter. A production app still needs a backend for:
- OTP authentication
- User accounts
- Video upload/storage
- Database
- Real likes/comments/follows
- Chat and voice messages
- Push notifications
- Content moderation/reporting
- Admin panel
- Privacy/security rules

The sample feed uses public demo video URLs. Replace them with your own storage/CDN URLs for production.
